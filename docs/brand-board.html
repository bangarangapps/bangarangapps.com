The sails

Jib and main replace the middle A of the name. Straight masts, flat feet, one billowed edge. The peak and the gap that widens toward the base give the A. Everything below is generated from one file (tools/wordmark.py), so every format matches.

Type is Archivo 900 with the width axis. The sails are the only coloured letter.

Rules

  • Clear space: half the height of the sails on every side.
  • Minimum: sail mark 14 px / 5 mm; wordmark 90 px / 25 mm wide.
  • One colour or sails-in-accent only. No gradients, outlines, shadows, rotation or skew.
  • Never redraw or re-typeset it. Export from the generator.
